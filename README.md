# Tennis AI

Pre-match tennis prediction prototype.

## v0.1
- Match win probability
- Set 1 probability
- Expected games
- Match score distribution
- Elo / surface Elo / form / serve / return model factors

Current player values are prototype fixtures, not live data. Next: licensed data source, historical backtest, calibration and automatic upcoming matches.

## Run
```
npm install
npm run dev
```
